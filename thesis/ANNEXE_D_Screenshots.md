# ANNEXE D — Captures d'écran

Ce fichier liste les captures d'écran recommandées à inclure dans la soutenance et où les enregistrer.

Destination recommandée: `docs/screenshots/` (créer si nécessaire)

Captures recommandées

1. Page d'accueil / Dashboard (`dashboard overview`)
2. Liste des projets (filtrage avancé activé)
3. Fiche projet (onglet KPI)
4. Gantt view montrant tâches et barres de progression
5. BI — onglet Exports (CSV / Excel / PDF)
6. BI — Audit logs (vérification d'intégrité)
7. Sortie d'un export (aperçu CSV ou excel ouvert)

Conseils
- Utiliser une résolution 1280×720 pour les slides.
- Nommer les fichiers `01-dashboard.png`, `02-projects.png`, etc.
- Inclure légendes courtes dans la présentation.
